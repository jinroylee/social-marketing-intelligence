# Plan a build-ready beauty intelligence pilot

Label: wayfinder:map
Status: resolved

## Destination

A build-ready specification for a small local-development beauty intelligence pilot with independent market monitoring and marketer-initiated campaign planning over fixed captured evidence. A marketer can investigate market insights, start a campaign from a brief, save an evidence-backed creator shortlist, define a measurement plan, and preserve the reasoning for later learning. The route is clear when the user workflows, development evidence and its limits, acceptance criteria, domain boundaries, and affordable implementation approach have been decided; live-source readiness is a later effort.

- Simultaneously validating every global market and product category. The shared model must support extension, while initial product validation is focused on Korean beauty products in Japan.
- An Instagram connector in the first acquisition flow, following the builder's 2026-09-29 TikTok-first scope change. The design still supports later platform additions.
- [Validate TikTok API access with a minimal read-only evidence sample](issues/10-validate-tiktok-api-access.md): the Business API prerequisite was closed without execution after the builder clarified that this route is unavailable and prioritized provider-independent architecture. A later live-source decision must evaluate a usable route separately.
- [Validate a Bright Data Japan profile and post sample](issues/21-validate-bright-data-live-sample.md): Deferred from this fixed-evidence map; a later one-creator API retry succeeded, while repeatability, additional creator coverage, quota and charges remain for source-readiness work.

- Campaign-outcome ingestion, sales attribution or lift calculation, representative market-change detection, broader language-quality calibration, and richer creator/audience coverage belong to later efforts. This pilot defines descriptive plans, bounded caption evidence, and exploratory decisions.
