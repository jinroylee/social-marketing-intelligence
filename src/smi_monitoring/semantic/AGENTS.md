# Provisional semantic X alerts

Own `SemanticAlerts`, `ControversyThreshold`, durable one-call assessment claims and atomic retained semantic alert/local-notification identities. Read [the semantic contract](../../../docs/monitoring.md#bounded-provisional-quality-controversy-assessments) and [ADR 0020](../../../docs/adr/0020-bounded-semantic-positions-full-input-policy.md) before changing method, support, dispatch or history.

Implement only the versioned product-quality mixed-position method. Require explicit operator thresholds and one exact frozen recent window. Classify all its at-most-20 capture texts; fixed labels and exact independently checked source spans remain provisional automated judgments. Count distinct native posts; repeated captures cannot multiply significance. Missing baseline means change is not assessed. Complete local coverage does not establish market completeness, semantic entailment, verified sentiment/controversy or human language/usefulness quality.

Depend on public `RecentMonitoring` policy/operator ports and the installed shared Responses/accounting route. Keep recent SQL/reconciliation in its owner and monetary admission/settlement in accounting. Grant no acquisition, task, topic-expansion, campaign or external-search authority. Quantitative detection remains independent in `alerts/`.

Commit a source-free claim before external I/O. Pin exact original window, full prepared model-input IDs/digest (including unresolved text), method/schema/threshold/model/bounds, requester and actual cost/usage linkage. Recheck all actual inputs and process/display/retain permission in shared admission's trusted dispatch guard after accounting contention; retain the recent policy lock through that commit. Repeat at finalization and reopen. Hold no transaction across model I/O. Exact requests and new requests for the same configured window reopen the first claim; interrupted/uncertain calls never automatically reissue.

Retain only source-free IDs, fixed positions and span offsets, never generated factual prose, copied excerpts or raw provider output. Resolve quotations from the original governed window on every read. Observed loss of any input permanently clears every dependent judgment; subsequent permission recovery and retries cannot reconstruct them. Preserve historical outcome and alert identity as unavailable history. Read current row state under the recent lock before returning it so concurrent purges cannot expose stale judgments.

Test public collection/detection/history/alert/inbox/accounting/HTTP behavior with real PostgreSQL and simulated external I/O. Fault-only DDL and PostgreSQL blocking metadata may coordinate failure/races; private collaborator mocks and direct-SQL outcome assertions are outside the approved seams. Keep method limitations and original source timing/coverage visible in browser views and update contracts, architecture, physical ERD and summaries with changes.

`read_alert(..., connection=...)` accepts the caller-owned local transaction for dependent context commits; retain the recent policy lock through it. The separate `../context/` owner composes existing-KB explanation; this detection owner keeps its own SQL and grants no new acquisition or model authority to context readers.
