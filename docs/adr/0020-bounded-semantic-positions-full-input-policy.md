# Bound semantic alerts to provisional positions and every actual model input

Status: accepted

One installed controversy method classifies retained X texts about product quality into concern, counterposition or unresolved positions. A configured threshold over distinct native posts produces a **possible** controversy signal. The model supplies exact input IDs and source span offsets, with no factual narrative or new source references. Independent validation establishes complete membership, fixed vocabulary and quotation accuracy; it cannot establish semantic entailment, verified sentiment, a shared disputed proposition, language accuracy or human usefulness. The method sacrifices fluent explanation and broad controversy coverage to make its provisional judgment inspectable without pretending that citation membership verifies generated claims. It has no baseline and makes no emerging/change-over-time claim.

Every supplied text can influence the assessment, including unresolved posts. The semantic owner pins the original window and full input IDs/digest, method/schema/threshold/model/bounds and attributable metered usage without caching source values. The shared admission guard checks those exact inputs and current process/display/retention permission after cost contention, retaining recent evidence's policy lock through dispatch commit. Model I/O follows commit; finalization repeats the check under the same owner port. A committed claim prevents silent reissue after lost responses, interruption or failed local finalization.

Retained positions and span offsets are source-dependent judgments. Policy-aware reopen permanently clears them if any original input is unavailable, preserving source-free historical outcome, method/window/cost lineage and alert/notification identity. Quotes always resolve from the original currently governed window. This is deliberately conservative: loss of an unresolved input withholds the whole finding, and observed permission recovery cannot regenerate it from retries. Notifications contain fixed templates, not a second prose cache. Reconciliation is synchronous on these public operations, without a background deletion guarantee. A new configured assessment is explicit new work.

Quantitative measurement remains in its independent owner and retains [its source-free lineage contract](0019-source-free-quantitative-alert-history.md). Semantic alerts use the same public recent-policy composition and local-notification shape, with distinct semantic identity/routes and provisional labels. Neither method grants topic, task, external-research or campaign authority; bounded existing-KB explanation is supplied by the separate [context owner](0021-pinned-local-alert-context.md), while explicit selective promotion is owned separately by [its lifecycle contract](0022-promoted-source-lifecycle-inheritance.md).
