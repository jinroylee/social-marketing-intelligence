# 31: Detect supported semantic X anomalies

**What to build:** A marketer can inspect semantic-shift or controversy alerts supported by retained recent X evidence and a versioned assessment method.

**Blocked by:** 13: Interpret natural-language criteria with one metered model; 30: Detect quantitative X anomalies with retained alerts.

**Status:** draft — awaiting breakdown approval; not published

**Size:** M — one bounded user-visible journey or extension in a fresh implementation context.

**Scope guard:** One bounded semantic method using the established metered model transport and alert contract; no external-search agent or new provider.

- [ ] Semantic assessment records method/model versions, selected windows/comparison context where applicable, actual recent support, uncertainty, and coverage limits.
- [ ] A significant supported semantic finding produces an alert and local notification distinguishable from a quantitative measurement.
- [ ] Malformed, unsupported, or source-injected generated output cannot invent support, approve work, expand monitoring topics, or call external research.
- [ ] Missing comparison context cannot be hidden behind a confident change claim; method limitations remain inspectable.
- [ ] Model calls obtain shared cost admission and usage attribution; default tests use controlled simulated responses and counted I/O.
- [ ] Alert copies and reopened support honor source permissions/retention withdrawal, with exact historical method/window references preserved.
