# Triage labels

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for an agent | `ready-for-agent` |
| Ready for a human | `ready-for-human` |
| Will not implement | `wontfix` |

Tickets produced from the approved implementation breakdown need no additional triage. Implementation execution uses the `claimed` and `resolved` lifecycle states described in [the local tracker](issue-tracker.md); these are execution states rather than additional triage roles.
