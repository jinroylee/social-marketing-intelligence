## What a consenting creator can supply

TikTok allows signup with an email and says an app **may be registered under an individual developer account**, although it recommends organization ownership for real integrations. This means a company email/organization is not a stated prerequisite for simply registering a regular developer app; it does **not** guarantee approval of this use case. Sandbox mode allows restricted testing without production app review, with up to 10 target TikTok accounts; production access requires review. [Register an app](https://developers.tiktok.com/docs/en/getting-started-create-an-app); [sandbox](https://developers.tiktok.com/docs/en/add-a-sandbox).

Production Display API prerequisites are an approved Login Kit and TikTok API integration, granted `user.info.basic` and `video.list` scopes, and authorization by the creator whose data is read. Optional `user.info.profile` and `user.info.stats` scopes cover profile link/bio/username and follower/following/likes/video counts respectively; the creator can grant only a subset of requested scopes. The returned `open_id` identifies the user **within this app**, and is not a general public-handle lookup key. [Setup](https://developers.tiktok.com/docs/en/display-api-get-started); [scope reference](https://developers.tiktok.com/docs/en/tiktok-api-scopes); [user fields](https://developers.tiktok.com/docs/en/tiktok-api-v2-get-user-info); [token consent](https://developers.tiktok.com/docs/en/login-kit-manage-user-access-tokens).

The documented read set is:

- `GET /v2/user/info/` for the consenting account's `open_id`, display name, avatar and, with additional scopes, username, bio, profile URL, verification and aggregate profile counts. [User info](https://developers.tiktok.com/docs/en/tiktok-api-v2-get-user-info).
- `POST /v2/video/list/` for that account's public videos, newest first, with a cursor; default 10 and maximum 20 videos per page. [List videos](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-list).
- `POST /v2/video/query/` for up to 20 video IDs **belonging to the authorized account**. The user token is mandatory; the endpoint is suitable for refreshing known authorized posts, not resolving another user's ID. [Query videos](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-query).

The [Display video object](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-object) documents ID, creation time, title/description, share/embed URLs, duration, image URL, dimensions, public view/like/comment/share counts and `is_aigc`. It documents **counts, not comment text**, audience-country composition, sales or conversion outcomes, campaign spend, or creator fees. No speech transcript or media-download field appears in that object. The cover image URL has a six-hour TTL, so storing it as a durable evidence asset is unsafe; query can refresh its URL. [Video object](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-object); [query videos](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-query).

Default documented endpoint rate limits are **600 requests per minute for each of user info, video list and video query**, enforced separately; this is a technical limit, not a usage grant or monthly budget. The user access token lasts 24 hours; its refresh token lasts 365 days initially and may rotate when refreshed. TikTok's Display guide explicitly illustrates periodic background refresh (12 hours in its example). [Rate limits](https://developers.tiktok.com/docs/en/tiktok-api-v2-rate-limit); [token management](https://developers.tiktok.com/docs/en/oauth-user-access-token-management); [Display guide](https://developers.tiktok.com/docs/en/display-api-get-started).

## App review and rights gates

TikTok's production review calls for a functioning, externally facing website, visible privacy policy and terms, configured redirect URI, a precise explanation of each requested scope, and an end-to-end integration demo video using sandbox for a first review. Apps still in development/testing or for private/personal use do not meet its normal approval criteria. The FAQ gives a typical several-days-to-two-weeks review range but TikTok's guidelines disavow a guaranteed timeline. Therefore a local-only ingestion pipeline is insufficient for production approval; sandbox testing may be a separate early experiment. [Review guidelines](https://developers.tiktok.com/docs/en/app-review-guidelines); [review FAQ](https://developers.tiktok.com/docs/en/getting-started-faq); [developer guidelines](https://developers.tiktok.com/docs/en/our-guidelines-developer-guidelines).

**Commercial analysis is a material unresolved permission question.** The [Developer Terms, II.1](https://t.tiktok.com/legal/page/global/tik-tok-developer-terms-of-service/en) permit automated collection **through the developer services** only as described in the documentation. The [Display API's stated purpose](https://developers.tiktok.com/docs/en/display-api-overview) is displaying a consenting creator's profile/videos. In [Developer Terms, III.3(c)](https://t.tiktok.com/legal/page/global/tik-tok-developer-terms-of-service/en), TikTok restricts use of its developer services for commercial purposes without **TikTok's express written consent**. Creator OAuth is that creator's permission for particular scopes; it is not stated to be TikTok's written commercial-use consent. The docs do not establish that routine app approval itself satisfies this clause for a creator-scoring/marketing-intelligence product. Obtain TikTok approval or written clarification for the described analytical use before treating this route as rights-cleared. This is a conservative reading of the text, **not a legal determination that TikTok will deny the use case**.

Separately, [Developer Terms, III.3(h)](https://t.tiktok.com/legal/page/global/tik-tok-developer-terms-of-service/en) restrict building or supplementing profiles/databases/records on individuals. A persistent scored creator database appears close to that boundary; whether TikTok would approve the exact design is unverified. The Terms' express exceptions for Commercial Content Library data are limited to its defined ad-transparency purposes and do not state an exception for Display API marketing analysis. [Developer Terms, I.2–4 and II.5](https://t.tiktok.com/legal/page/global/tik-tok-developer-terms-of-service/en). User authorization, endpoint availability and no API fee do not settle these use-rights questions.

TikTok currently states that it does not charge for Developer Services, but reserves future fees. It does not thereby quote a price for third-party data, app development, hosting, or legal clearance. The reviewed Display docs give no general field-retention period. The [Developer Terms, VI](https://t.tiktok.com/legal/page/global/tik-tok-developer-terms-of-service/en) require deleting TikTok information acquired through the Developer Services upon termination; the [developer guidelines](https://developers.tiktok.com/docs/en/our-guidelines-developer-guidelines) require safeguarding user data and respecting consent. Do not treat the absence of a general retention number as unlimited retention. A production design still needs a documented deletion/revocation and derived-data policy, plus TikTok confirmation for this intended processing.
