# Campaign recommendation application

Own the save-first composition of campaign recommendation/discovery and explicit post-completion regeneration. `CampaignRecommendations.recommend` delegates deterministic/model recommendation to `CampaignStore`, then submits that saved shortlist's coverage need through `AcquisitionTasks`. `read` joins their public views. Construct both owners for the same database/workspace and configure the automation's campaign role at the trusted application boundary.

Campaigns own the immutable coverage policy/clock/inputs and recommendation. Tasks own the one-per-shortlist disposition and task transaction. Preserve this dependency direction: campaign core does not import tasks, and this composition writes only its task-owned `campaign_regeneration_requests`; all foreign data uses public readers/operations. A failed admission cannot roll back a saved recommendation. Retries reopen both owners' exact historical results; the worker owns later cost waiting/resume. Source/model I/O never belongs in a transaction here.

Read [the automatic discovery contract](../../../docs/campaigns.md#automatic-coverage-and-discovery) before changing scope derivation, admission retries or visibility. Forms/model/source text cannot assign campaign authority, query configuration or spending controls. Discovery completion does not change shortlist history.


Before changing completion actions or retry recovery, read [explicit regeneration](../../../docs/campaigns.md#explicit-regeneration-after-discovery). `regeneration_offer` joins `CompletionInbox`, source-free `CampaignStore.read_shortlist_context` and action history. `regenerate` requires actual human initiation, server automation and configured campaign authority for a new request. Persist its exact body/actors and fresh server-owned recommendation identity before assessment; retain only source-free outcome IDs/status. Reuse the original saved deterministic/ranked method and existing `recommend` composition, with current brief/profile/heads and no fallback. Exact completed actions reopen before current source/brief/configuration checks; unfinished receipts reopen the existing campaign claim/save and preserve no-reissue guarantees. Keep all locks/transactions outside model/source I/O. Event storage remains identity/task/time; never copy source text into request bodies/outcomes or reconstruct purged reasons.
