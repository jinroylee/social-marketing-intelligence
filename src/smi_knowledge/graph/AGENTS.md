# Governed knowledge graph

Own `KnowledgeGraph.search/read`, `GraphScope`, `GraphTraversal`, and the source-free graph-search manifest. A search pins one bounded `KnowledgeQueries` result plus human filter input and actual requester. Reopening projects native subjects, observed authorship, published Brand/Product mentions and their exact human catalog associations through public query/catalog readers.

Evaluate process, display, retention and current derivation health together on every read, under one caller transaction. Withhold denied nodes, incident edges, labels and evidence; an unavailable selected token returns a content-free state. Keep source values, excerpts and catalog names in their owning stores. Later publications never replace the pinned support. The graph is an exploration view, not an immutable campaign judgment.

Keep platform/namespace/kind/native ID identities distinct. Human catalog references retain their business IDs and attribution; literal mentions remain provisional derived claims. Adjacency and matching handles establish neither Creator identity nor endorsement. Exact edge support retains assertion/interpretation IDs, source dates, mapper/catalog methods and producer attribution.

Bound scans through the public query scope. Omitted traversal preserves the original direct neighborhood; explicit traversal uses finite hop/node/relationship/edge-inspection budgets with cycle-safe breadth-first order. Inspection bounds begin after the existing finite projection/adjacency build. Expose empty/truncated results and count only permitted projection values. Neighbor filters apply at every step; exact observation filters narrow the whole projection, including shared-node labels/details, while original support manifests remain intact. Keep navigation transient and opaque; retained URL context grants no historical graph or campaign authority. Acquisition, model/provider calls, inferred identities and sibling-private calls or foreign-owner SQL belong outside this owner. Schema changes update the physical ERD; interface and UI changes update the knowledge/review contracts and public/HTTP tests.
