# Domain documentation for agents

Before naming domain concepts or changing interfaces, read the root [glossary](../../GLOSSARY.md) and the [ADRs](../README.md) relevant to the owner being changed. Use the glossary's distinctions among source references, observations, interpretations, tasks, publications and decisions.

This is a single-context repository: `GLOSSARY.md` and `docs/adr/` are the shared vocabulary and durable decisions. Follow [the documentation index](../README.md) to the owner's current contract. Distinguish installed behavior from accepted future design and keep physical ERDs aligned with implemented schemas. Flag a material conflict with an accepted ADR rather than silently reversing it.
