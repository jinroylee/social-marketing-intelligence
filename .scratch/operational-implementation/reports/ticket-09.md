# Ticket 09: attributable synthetic usage and separate forecasts

Status: implemented locally; ticket remains claimed for integration verification.

## Installed behavior and public interfaces

- New independent `smi_costs.CostScope` / `UsageAccounting(db, workspace_id='local', task_attribution=resolver)` owns three PostgreSQL tables: immutable operator `cost_scopes`, stable actor/method/request-bound `cost_operations` and append-only workspace-global `cost_entries`. The wheel registers/packages this owner, schema and local view. `smi-ingest migrate` installs its idempotent migration.
- `configure_scope(scope, human_actor)` persists explicit provider/service, metered or forecast-only classification, uppercase three-letter currency, UTC start-inclusive/end-exclusive period, and synthetic unit/rate/version for metered scopes. Only trusted workspace humans configure. Changed classification/rate/currency/period under an existing identity conflicts. Missing configuration fails visibly. This milestone's metered configuration is always explicitly synthetic; no commercial price is supplied or researched.
- `begin_operation(scope_id, actor, request_id=..., method=..., task_id=None, attempt_id=None)` commits stable operation identity before measurement. Identical concurrent retries reopen one operation; changes to actor, method, scope or task/attempt conflict. Synthetic model operations retain actual actor, versioned method, service/provider and retry identity without requiring acquisition tasks.
- `AcquisitionTasks.resolve_cost_attribution(task_id, attempt_id, actor)` is the injected public task-owner seam. It normalizes UUIDs, reopens the real workspace task through `read`, and verifies exact attempt membership. Foreign/nonexistent tasks and unrelated/nonexistent attempts fail. Accounting imports no task code and queries no task/attempt tables; tasks import no accounting code. Stored task/attempt IDs are validated logical references, keeping the dependency graph acyclic for ticket 10 composition.
- `record_usage(... measurement_id, units, rate_version, measured_at, provenance)` derives auditable synthetic amounts from exact units and immutable versioned rate. Entries retain unit, rate/version, amount, measurement source/time, actual recorder and database recording time. Numeric strings/Decimal/integers are finite/nonnegative, bounded through 10^18 with at most 12 fractional places and exponent −12 through 18. Floats, booleans, negatives, invalid/nonfinite values and unsupported precision are rejected. Products/totals use an independent 80-digit decimal context and canonical decimal strings, including under altered caller precision/exponents; explicit measured zero remains distinguishable from missing data.
- `record_forecast` requires an explicit amount/currency and assumptions; `record_commitment` records a declared outstanding synthetic amount in metered scopes; `record_uncertainty` retains `unknown` or `meter_failure` with source-free provenance/time/reason. These are distinct entry kinds. Failure never silently reclassifies a metered scope. Late usage can add known measured cost while unknown/failure coverage remains visible.
- Every record uses one workspace-global measurement identity. Identical concurrent/restarted retries reconcile once; changed units, provenance, kind, recorder or operation under that identity raise visible `cost_measurement_conflict` while preserving the original entry. Canonical/uppercase operation UUIDs retain one measurement identity. Scope/operation identities also retain immutable original attribution.
- `read` exposes exact configuration/operator/time, actor/method, task/attempt, full entry provenance and separate actual/forecast/commitment totals. Missing categories are null/Unknown, never zero. Measured amounts report `synthetic: true`, `commercial_charge: false`, and all reads report `enforced_monetary_control: false`. No currency/period conversion or combined total is invented. `list(actor, task_id=None)` is newest-100 presentation only; older identities remain directly readable.
- **Costs**, `GET /costs`, `GET /costs/OPERATION_ID`, and task detail's `GET /tasks/TASK_ID/costs` delegate to the public owner. The task-filtered HTTP route reopens the actual task first. Pages escape all metadata, visibly separate synthetic actuals/forecasts/outstanding commitments/unknown failures, show assumptions and exact attribution/provenance, and state **No commercial charge** and **No enforced monetary ceiling**. There are no browser rate/usage configuration forms, worker execution or provider calls.
- Accounting contains only source-free operational identifiers, not source values, URLs, prompts/responses, credentials or copied explanation text. Workspace checks remain real. Withdrawing publication support leaves historical synthetic usage readable without copying denied source values.
