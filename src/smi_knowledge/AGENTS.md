# Shared knowledge

Own Brand/Product references, immutable extraction catalogs and evidence-backed caption interpretations. Public entry points are `KnowledgeStore` and `Catalog`. Read input through `EvidenceSetReader`; ingestion continues to own observations and source assertions.

Catalog names/aliases are attributable human configuration, distinct from source observations and development curation. Caption rules return typed provisional interpretations with exact Unicode character offsets, source assertion IDs and method versions. A matching alias supports a mention at the catalog's specificity, not efficacy, audience geography or sales.

Persist source-derived copies only when retention is allowed. Reconcile policy before reads and preparation: withdrawn copies are purged, display/process-denied inputs are excluded for their purpose, and superseded support requires review. A purged interpretation cannot be silently regenerated by retrying the same run.

Preparation request IDs distinguish explicit new work from retries. Keep historical results/tombstones immutable; a new request can recover newly permitted evidence without changing its catalog or method.

Keep core rules category/market independent. Category lexicons belong in catalog configuration. New business decisions belong to campaign/monitoring modules. Update `docs/knowledge.md`, architecture and the physical ERD with changes to storage or public behavior.
